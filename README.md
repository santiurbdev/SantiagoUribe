# 🏨 Sistema de Gestión de Cadena Hotelera - MySQL

Este repositorio contiene la arquitectura relacional y lógica avanzada de base de datos para un sistema completo de gestión de una cadena hotelera (multi-propiedad), desarrollado en **MySQL**.

## 🚀 Contenido del Repositorio

El proyecto se encuentra estructurado en los siguientes scripts SQL:

1. **`Santiago Uribe - hotelpro.sql`**: Esquema principal de la base de datos con **25+ tablas** normalizadas e inserción de datos iniciales.
2. **`INNER hotelpro.sql`**: Consultas complejas utilizando **`INNER JOIN`** para relacionar huéspedes, reservas, habitaciones y pagos.
3. **`Views And Stored Procedures - hotelpro.sql`**: Vistas para simplificar reportes y Procedimientos Almacenados (*Stored Procedures*) para la automatización de procesos.
4. **`Triggers And Fuctions - hotelpro.sql`**: Disparadores (*Triggers*) para auditoría/validación y Funciones personalizadas.
5. **`Events - hotelpro.sql`**: Eventos programados de mantenimiento y tareas automáticas.

## 🛠️ Tecnologías Utilizadas

* **Gestor de Base de Datos:** MySQL
* **Cliente SQL:** HeidiSQL
* **Modelado y Consultas:** DDL, DML, DCL, TCL, Triggers, Vistas, Funciones y Stored Procedures.
